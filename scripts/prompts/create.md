# Area: Create

Create problems are an open prompt with a constraint: write a short piece (a micro-story, a pitch, a slogan set, a rule for a game) under a limit that forces choices. There is no single right answer.

## Difficulty

- 3: one clear constraint (a word limit, a forbidden letter or word).
- 4: two interacting constraints, or a constraint that asks for a structural trick.
- 5: see the deep problem notes when provided.

## Pitfalls

- Ambiguous wording: state the limits (`minWords`, `maxWords`) and what counts toward them.
- Answers that need outside knowledge: the prompt must not depend on a specific book, film or person.

The `authorNote` explains what a strong response does, for the owner reading it later.
