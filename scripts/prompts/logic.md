# Area: Logic

Logic problems are deductions: knights and knaves, grid puzzles, rule finding, and ordering. The answer follows from the statements alone.

## Difficulty

- 2: the only daily band for Logic; a few statements or a small grid, solvable in a few minutes with careful reasoning.
- 5: see the deep problem notes when provided.

## Pitfalls

- Ambiguous wording: state every rule explicitly and make sure exactly one answer satisfies all of them.
- Answers that need outside knowledge: do not rely on facts about the real world.
